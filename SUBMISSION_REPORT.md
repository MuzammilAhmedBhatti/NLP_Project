# ModPrecedent — NLP Course Submission

## Problem

ModPrecedent predicts whether Meta's Oversight Board is likely to uphold or overturn a content-moderation action. It also retrieves relevant policy passages and earlier decisions so the prediction can be inspected against evidence.

This is a retrieval-augmented generation problem rather than standalone sentiment analysis or fake-news classification. It combines document processing, lexical and dense retrieval, constrained generation, policy-label extraction, temporal leakage controls, and evidence traceability.

The result screen also provides a multi-turn, LangChain LCEL follow-up conversation grounded in the analyzed case and retrieved citations. Each follow-up performs conversational query expansion and fresh hybrid retrieval. Claude Haiku handles natural conversation and unexpected questions in the configured live application. MiniLM routes bounded case operations, while deterministic grounded handlers cover definitions, poster revisions, corpus statistics, critique framing, and history recap. A response validator catches prompt leakage, repetition, very short output, and advice aimed at the wrong actor. Local Qwen remains the automatic fallback.

## Pretrained models

- Default local prediction and conversation model — `Qwen/Qwen2.5-1.5B-Instruct`
- Automatic low-resource fallback — `Qwen/Qwen2.5-0.5B-Instruct`
- Optional live-demo model — `claude-haiku-4-5-20251001`
- Dense embedding model — `sentence-transformers/all-MiniLM-L6-v2`
- Optional local API backend for interactive use — Ollama with `llama3.1:8b`

No model is trained from scratch. The saved evaluation is the reproducible local-Qwen baseline. The live bot can use Claude Haiku through a configurable provider adapter and falls back locally if API access fails. Ollama and OpenAI-compatible adapters remain available through environment configuration.

## Data

- 94 processed public Oversight Board decisions
- 44 Standard decisions and 46 Summary decisions
- 12 leakage-safe Standard-decision evaluation cases, balanced 6 upheld and 6 overturned
- Inputs contain case facts and Meta's original action
- Labels contain the Board outcome and applicable policies

The review set is intentionally small and should be treated as a course demonstration. It is insufficient for claims about real-world generalization.

## Compared systems

| System | Input |
|---|---|
| S0 | Case description and original Meta action |
| S1 | S0 plus retrieved policy passages |
| S2 | S1 plus analogous earlier decisions |

For every held-out case, the retriever excludes all reviewed cases and documents published on or after the case date. This prevents the target decision and future documents from leaking into its evidence.

## Final evaluation

| System | Cases | Accuracy | Macro F1 | Policy F1 | Valid inline citation coverage |
|---|---:|---:|---:|---:|---:|
| S0 | 12 | 0.583 | 0.556 | 0.056 | 0.000 |
| S1 | 12 | 0.750 | 0.733 | 0.089 | 1.000 |
| S2 | 12 | 0.500 | 0.486 | 0.089 | 1.000 |

These results were generated by running `python -m modprecedent.evaluation.experiments`. The complete predictions, metrics, accuracy chart, and retrieval-sensitivity table are stored in `reports/generated/latest/`.

The conversational regression audit contains 22 representative paraphrased questions and currently routes all 22 correctly. It is reproducible with `python -m modprecedent.evaluation.conversation_audit`; its CSV and Markdown artifacts are included. This is a bounded regression result rather than a claim that every possible natural-language question will be answered perfectly.

The software suite contains 25 passing automated tests. Every source function has a concise purpose docstring so the collection, preprocessing, retrieval, generation, evaluation, and interface code can be explained module by module.

The remaining substantive limits are local-model policy-label extraction, CPU inference latency, and the moderate corpus size. The application-side NLP pipeline includes preprocessing, OCR plus optional local visual captioning, sparse and dense retrieval, semantic routing, query expansion, grounded generation, conversation memory, validated citation IDs, fallback behavior, and reproducible evaluation.

Policy retrieval improved outcome accuracy from 58.3% for S0 to 75.0% for S1. Adding precedents reduced accuracy to 50.0%, indicating that analogous cases introduced distracting or conflicting context for the small local model. Policy-label F1 remained below 0.09, so policy extraction needs a stronger model or a dedicated multilabel classifier. The result supports the RAG methodology without claiming that every retrieval configuration helps.

## Reproduction

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[all]"
python -m pytest
python -m modprecedent.evaluation.experiments
modprecedent-app
```

The first experiment run downloads the configured pretrained Hugging Face models. The application accepts typed text or an image, extracts text with RapidOCR, optionally adds a local BLIP visual description, and reports a clear error when no usable text is detected.
